What's inside

💬

Accounts, friends & chat

  • Sign up / log in with a username and password
  • Mutual friend requests — accept once, friends both ways
  • 1-on-1 DMs as clickable friend circles
  • Create or join rooms by a shared code
  • Saved rooms with your own labels, one tap back in
  • Stays open in Chrome's side panel while you browse
🛡️

Roles & moderation

  • Group Creator → Admin → Moderator → Member hierarchy
  • Promote, demote and kick — always with a confirmation step
  • Admin Panel: ban/unban, reset passwords, delete rooms
  • Read-only room & DM review for moderation, disclosed up front
  • 🚩 Report a chat to send admins the last 30 messages
  • Site-wide announcements, text or voice
🎮

Games & sound

  • Live Tic-Tac-Toe, Connect 4 & Rock-Paper-Scissors
  • Challenge anyone in a DM or room — others can spectate
  • Soundboard: air horn, sad trombone, dog whistle & more
  • Record or upload your own clips, loud by default
  • Text-to-speech broadcasts, read aloud instantly
  • Desktop pop-ups even when the panel's closed
🎨

Make it yours

  • 7 themes: Dark, Light, Midnight, Ocean, Forest, Sunset, High Contrast
  • Per-person notification toggles for every category
  • Colored usernames throughout every chat

Install it

  1. Download the latest release above and unzip it.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and select the folder containing manifest.json.
  4. Click the extension icon to open the side panel, then Sign Up. The first account created becomes the Owner.

Runs against a Firebase Realtime Database. Point it at your own by publishing this rule:

{ "rules": { ".read": true, ".write": true } }

Full setup notes are in the repo's README.
